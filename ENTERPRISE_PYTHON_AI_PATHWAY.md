# Enterprise Python & AI Engineering Pathway

## Objective

Train learners to design, build, test, secure, release and operate enterprise-scale Python systems using FastAPI, containers, CI/CD, Kubernetes, LLMs, RAG and Model Context Protocol.

## Qualification ladder

1. Professional Python Engineer
2. FastAPI Backend Engineer
3. CI/CD and Container Engineer
4. Kubernetes Application Engineer
5. LLM and RAG Engineer
6. Enterprise AI Architect

## Final capstone

Build a governed enterprise knowledge and workflow assistant with:

- componentized FastAPI services
- PostgreSQL and migrations
- authentication, RBAC and audit logging
- background workers and queues
- cited, permission-aware RAG
- MCP tools and resources
- structured LLM outputs and evaluation
- Docker, CI/CD, Kubernetes and Helm
- logs, metrics, traces, health probes and rollback

## Evidence standard

Learners must submit code, tests, architecture decisions, threat modelling, deployment evidence, evaluation results and an operational runbook.
